Yapay Zekâ Kullanım Notları

1. Kullanım Amacı

Bu projede yapay zekâdan HTML sayfalarının yapısını oluşturmak, CSS tasarımını geliştirmek ve JavaScript kodunun mantığını anlamak için destek alınmıştır.

2. Kullanılan Promptlar

Prompt 1: HTML Yapısı

"Üniversite öğrencileri için üç sayfalı bir kampüs kulübü web sitesi oluştur. Ana sayfa, etkinlikler ve hakkımızda sayfalarını HTML ile hazırla."

Değerlendirme: Önerilen sayfa yapısı incelendi. Sayfalar arasındaki bağlantılar ve içerikler projenin ihtiyaçlarına göre düzenlendi.

Prompt 2: CSS Tasarımı

"Mevcut HTML sayfaları için yeşil ve krem renklerini kullanan, kart tasarımlarına sahip ve mobil cihazlara uyum sağlayan bir CSS dosyası hazırla."

Değerlendirme: CSS kuralları incelendi. Mobil ekranlarda kartların tek sütuna geçmesini sağlayan medya sorgusu kullanıldı.

Prompt 3: JavaScript Arama

"Etkinlik kartlarını arama kutusundaki kelimeye göre filtreleyen, sonuç sayısını gösteren ve aramayı temizleyen JavaScript kodunu açıkla."

Değerlendirme: Arama kodu incelendi. Etkinliklerin metinleri karşılaştırılarak eşleşen kartların gösterilmesi sağlandı.

3. Kod Açıklamaları

addEventListener

Bir HTML öğesinde gerçekleşen olayları dinlemek için kullanılır. Bu projede arama alanındaki yazı değiştiğinde filtreleme işlemini başlatır.

includes

Bir metnin başka bir metni içerip içermediğini kontrol eder. Etkinlik kartlarının aranan kelimeyle eşleşmesini belirlemek için kullanılır.

trim

Metnin başındaki ve sonundaki boşlukları kaldırır. Böylece arama yapılırken gereksiz boşluklar sonucu etkilemez.

4. İnsan Kontrolü

Yapay zekâ tarafından önerilen kodlar doğrudan doğru kabul edilmemelidir. Kodların çalışma mantığı incelenmeli, site üzerinde test edilmeli ve bulunan hatalar düzeltilmelidir.
